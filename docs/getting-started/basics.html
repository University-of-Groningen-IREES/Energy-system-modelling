Python and Jupyter Basics#

In this lesson, we create a notebook and practise calculations, variables, and comparisons in Python.

Before starting, complete Getting Ready: Miniforge. Your course environment and JupyterLab should already be installed.

Open JupyterLab#

If JupyterLab is already running, continue to the next section.

Otherwise, open Miniforge Prompt on Windows or Terminal on macOS and run:

conda activate managing-data

Then launch JupyterLab:

jupyter lab

Keep the terminal open while you work.

If you are using Google Colab, open Colab and select New notebook.

Create a new notebook#

In JupyterLab:

  1. Navigate to the folder where you want to save your notebook.

  2. Click File → New Launcher, or click the + button.

  3. Under Notebook, select Python 3. The label may also include the kernel name, such as ipykernel.

  4. Right-click the notebook’s tab and select Rename Notebook.

  5. Name it 01-python-basics.ipynb.

The .ipynb extension identifies a Jupyter notebook.

Understand notebook cells#

A notebook combines two main types of cells:

  • Code cells contain Python instructions that you can execute.

  • Markdown cells contain explanations, headings, lists, and equations.

You can change a selected cell’s type using the dropdown menu in the notebook toolbar.

Run your first code cell#

In a code cell, enter:

print("Hello, energy modellers!")

Press Shift + Enter.

The output appears below the cell:

Hello, energy modellers!

Shift + Enter runs the selected cell and moves to the next one. Ctrl + Enter runs it while keeping the same cell selected.

Add a Markdown cell#

Select an empty cell and change its type from Code to Markdown.

Enter:

## My first calculation

In this notebook, I will calculate energy consumption using Python.

Press Shift + Enter to display the formatted text.

Save your notebook#

Use File → Save Notebook, or press:

  • Ctrl + S on Windows.

  • Command + S on macOS.

Order of operations#

Multiplication and division are evaluated before addition and subtraction:

2 + 3 * 4

The result is 14.

Use parentheses to change the order:

(2 + 3) * 4

The result is 20.

Store values in variables#

A variable gives a name to a value. Use = to assign that value:

power_kw = 2
duration_hours = 3

We can then use these variables in a calculation:

energy_kwh = power_kw * duration_hours

print(energy_kwh)

The result is 6: operating at a constant power of 2 kW for 3 hours uses 6 kWh of energy.

Python does not automatically check physical units. Use consistent units and choose variable names that explain what the values represent.

Variable names#

Variable names:

  • Can contain letters, numbers, and underscores.

  • Cannot start with a number.

  • Cannot contain spaces.

  • Are case-sensitive: power_kw and Power_kw are different names.

For example:

electricity_price_eur_per_kwh = 0.30

cost_eur = energy_kwh * electricity_price_eur_per_kwh

print(cost_eur)

Decimal numbers use a point, such as 0.30, rather than a comma.

Add comments#

Comments explain your code. Python ignores text following # on the same line:

# Calculate consumption at constant power
energy_kwh = power_kw * duration_hours

print(energy_kwh)

For example:

The result is True.

energy_kwh == 10

The result is False.

Remember: = assigns a value, while == compares values.

Run cells in order#

A notebook’s kernel is the process that executes your Python code and holds variables in memory.

Run cells from top to bottom. A variable must be defined before a later cell can use it.

For example, this calculation requires power_kw and duration_hours to have been defined:

energy_kwh = power_kw * duration_hours

If you change an input value, run the calculation again to update the result.

Restarting the kernel clears variables from memory. Your saved code remains in the notebook, but you must run it again.

In JupyterLab, use Kernel → Restart Kernel and Run All Cells to check that your notebook works from beginning to end.

Practice#

An appliance operates at a constant power of 1.5 kW for 4 hours. Electricity costs 0.30 EUR/kWh.

In a new code cell:

  1. Store the power, operating time, and electricity price in variables.

  2. Calculate the energy consumption in kWh.

  3. Calculate the electricity cost in euros.

  4. Check whether consumption exceeds 5 kWh.

  5. Display your results using print().

Save your notebook when you finish.
